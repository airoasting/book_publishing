# Book Writer

**책의 제목과 목차만 정해 주세요. 나머지는 AI가 합니다.**

Book Writer는 Claude와 ChatGPT에서 쓸 수 있는 책쓰기 스킬입니다. 자료 조사부터 초안 작성, 9명의 평가자 검수, 최종 Word 문서(.docx) 변환까지 책 한 권이 만들어지는 전 과정을 자동으로 진행합니다.

## 이런 분께 맞습니다

- 책을 쓰고 싶은데 어디서부터 시작할지 막막한 분
- 실용서, 가이드북, 사내 매뉴얼을 빠르게 만들고 싶은 분
- AI가 쓴 초안을 그냥 받는 게 아니라, **검증과 리뷰를 거친 원고**를 원하는 분

코딩 지식은 필요하지 않습니다. 채워야 할 파일은 하나뿐입니다.

## 시작하기

### 1. 준비물

- [Claude Code](https://claude.com/claude-code) (데스크톱 앱 또는 터미널)
- 이 폴더

### 2. 설치

Claude Code를 열고 아래 주소를 붙여 넣으면서 이렇게 말하면 끝입니다.

```
https://github.com/airoasting/book_publishing
이 주소의 스킬을 다운로드해서 내 스킬 폴더에 설치해줘
```

Claude가 알아서 내려받아 `홈 > .claude > skills > book-writer`에 설치해 줍니다. 직접 하고 싶다면 위 주소에서 초록색 Code 버튼 > Download ZIP으로 내려받아, 압축 푼 폴더를 그 위치에 넣어도 같습니다.

### 3. 책 정보 채우기

`book/user-book-toc.md` 파일을 열고 내 책의 정보를 채웁니다.

| 채울 항목 | 예시 |
|-----------|------|
| 제목, 필명 | "NotebookLM 활용법", AI ROASTING |
| 대상 독자 | 직장인, 실무자 |
| 목차 | 프롤로그, 1부~N부, 에필로그, 부록 |
| 말투(페르소나) | 옆자리 선배가 알려주는 톤 |
| 분량 목표 | 240~250페이지 |

**다른 책을 쓰고 싶을 때도 이 파일 하나만 바꾸면 됩니다.** 나머지 파일은 손대지 않습니다.

### 4. Claude에게 말하기

Claude Code를 열고 이렇게 말합니다.

```
책 써줘
```

그러면 스킬이 알아서 4단계를 순서대로 진행합니다. 단계별로 따로 시키고 싶으면 이렇게 말해도 됩니다.

| 하고 싶은 일 | 이렇게 말하세요 |
|--------------|-----------------|
| 자료 조사 | "리서치 시작해줘" 또는 `/research` |
| 목차 설계와 초안 | "초안 써줘" 또는 `/write` |
| 원고 검수 | "리뷰 돌려줘" 또는 `/review` |
| Word 문서 만들기 | "출판해줘" 또는 `/publish` |

### 5. 결과물 받기

모든 단계가 끝나면 `output/날짜/` 폴더에 세 파일이 생깁니다.

- `final.docx` : 완성된 책 원고 (Word 문서, 이미지 포함)
- `metadata.md` : 도서 소개문, 검색 키워드, 가격 전략 등 출판 준비 자료
- `verify-report.md` : 자동 검사 결과와 10점 만점 자가 채점

## ChatGPT에서도 쓸 수 있습니다

1. 아래 주소에서 초록색 Code 버튼 > Download ZIP을 눌러 내려받고 압축을 풉니다.

   ```
   https://github.com/airoasting/book_publishing
   ```

2. ChatGPT에서 새 프로젝트(또는 GPT 만들기)를 열고, 지시문에 `SKILL.md` 내용을 붙여 넣습니다.
3. `references/` 폴더의 문서 4개와 `scripts/verify.py`, 그리고 내 책 정보를 채운 `user-book-toc.md`를 파일로 업로드한 뒤 "책 써줘"라고 말합니다.

자동 검사와 Word 변환은 파이썬 코드를 실행할 수 있는 환경이 필요합니다. Claude Code에서는 기본으로 동작하고, ChatGPT에서는 데이터 분석(코드 실행) 기능이 켜져 있어야 합니다.

## 어떻게 품질을 지키나요

초안을 그대로 내보내지 않습니다. 세 겹의 검수를 거칩니다.

1. **9명의 평가자 리뷰**. 비평가, 일반 독자, 합평단 5인(사실·구조·논리·독자·서식 검증), 편집자, 교정 전문가가 차례로 원고를 읽고 지적합니다. 반드시 고쳐야 할 문제(🔴)가 하나라도 남아 있으면 다음 단계로 넘어가지 않습니다.
2. **자동 검사 12항목**. 사람이 놓치기 쉬운 것(금지 부호, 목차 누락, 분량 미달, 말투 섞임 등)을 프로그램이 잡아냅니다. 통과해야만 Word 변환이 시작됩니다.
3. **10점 만점 자가 채점**. 남은 결함 수를 기준으로 점수를 매기고, 9점 미만이면 출판 보류를 권합니다.

## 중간에 끊겨도 괜찮습니다

긴 작업이라 대화가 중간에 끊길 수 있습니다. 모든 산출물에는 완료 도장(상태 마커)이 찍히기 때문에, 새 대화에서 "이어서 해줘"라고 하면 끊긴 지점부터 정확히 이어서 작업합니다. 이미 쓴 내용을 덮어쓰지 않습니다.

## 폴더 구성

```
book-writer/
├── SKILL.md              스킬의 작동 규칙 (수정하지 않음)
├── book/
│   └── user-book-toc.md  ★ 내 책 정보 (유일하게 편집하는 파일)
├── references/           단계별 실행 문서 4개 (수정하지 않음)
├── scripts/              원고 자동 검사기 (수정하지 않음)
├── assets/               썸네일 이미지
├── draft/                작업 중인 원고가 쌓이는 곳 (자동 생성)
└── output/               완성된 docx가 나오는 곳 (자동 생성)
```

## 작업 중에 draft 폴더에 쌓이는 것들

책 한 권을 쓰는 동안 모든 중간 원고가 `draft/날짜/` 폴더 안에 순서대로 쌓입니다. 한 권 = 폴더 하나라서, 여러 책을 작업해도 서로 섞이지 않습니다. 번호 순서대로 리서치 노트에서 최종 원고까지 이어집니다.

```
draft/
└── 20260711/                     ← 이 책의 작업 폴더 (시작한 날짜)
    ├── 01_research-notes.md        리서치: 조사 자료
    ├── 02_outline.md               집필: 목차 설계
    ├── 03_draft-v1.md              집필: 첫 초안
    ├── 04_review-red.md            리뷰: 비평가 지적
    ├── 05_draft-v2.md              리뷰: 비평 반영본
    ├── 06_review-pink.md           리뷰: 독자 지적
    ├── 07_draft-v3.md              리뷰: 독자 반영본
    ├── 08_ensemble-review-1.md     리뷰: 합평단 5인 1차
    ├── 09_draft-v4.md              리뷰: 합평 반영본
    ├── 10_ensemble-review-2.md     리뷰: 합평단 5인 2차
    ├── 11_draft-final.md           리뷰: 최종 원고
    ├── 12_review-editor.md         리뷰: 편집자 지적
    ├── 13_review-marketer.md       리뷰: 마케터 의견
    └── 14_review-proofreader.md    리뷰: 교정 지적
```

번호가 붙은 이 파일들이 곧 작업 기록입니다. 각 단계가 원고를 어떻게 바꿨는지 되짚어 볼 수 있고, 중간에 끊겨도 이 폴더를 보고 정확히 이어서 작업합니다. 완성된 `final.docx`는 `draft`가 아니라 같은 날짜의 `output/날짜/` 폴더에 따로 나옵니다.

이 폴더들은 자동으로 만들어지므로 미리 준비할 필요가 없습니다. 작업이 끝난 뒤 중간 원고가 필요 없으면 `draft/날짜/` 폴더째로 지워도 됩니다.

## 자주 묻는 질문

**Q. 책 한 권 쓰는 데 얼마나 걸리나요?**
분량에 따라 다르지만, 240페이지 기준으로 여러 번의 대화에 나눠 진행됩니다. 초안 작성 시 한 번에 얼마나 쓸지(부 단위로 끊을지, 끝까지 갈지)를 처음에 한 번 물어봅니다.

**Q. 조사 자료는 믿을 수 있나요?**
모든 출처에 신뢰도 등급(Tier 1~3)을 붙입니다. 공식 문서와 정부·기관 자료를 최우선으로 쓰고, 개인 블로그나 SNS는 사실의 근거로 쓰지 않습니다.

**Q. 표지도 만들어 주나요?**
표지는 이 스킬의 범위 밖입니다. 완성된 원고와 함께 디자이너나 표지 제작 도구를 이용하세요.

**Q. 영어 책도 쓸 수 있나요?**
현재는 한국어 책에 맞춰져 있습니다. `book/user-book-toc.md`의 작성 스타일을 바꾸면 시도할 수는 있지만, 검수 규칙 일부(어미 통일 등)는 한국어 기준입니다.
